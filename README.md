# SYLUTION — The Digital Lab

A high-end, animation-led React/Vite website for **SYLUTION**, a deeptech engineering company building intelligent devices, robotic systems, digital products, and AgriTech.

## Included

- Premium white / black / deep-red design system
- Cinematic preloader with progress indicator
- Responsive sticky navigation and mobile menu
- Hero technology core visual with generated engineering asset
- Idea-to-product staged storytelling
- Robotics lab section with hotspots and build categories
- Interactive technology network
- Products showcase for BESE26, FarmX, and FarmX AI
- Build-with-SYLUTION live system configurator
- Smart agriculture visual section
- Training, About, and project inquiry sections
- Form confirmation state
- Responsive layout and `prefers-reduced-motion` support
- Original generated visual assets in `public/assets`

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

This is a static frontend foundation. Product, project, CMS, and inquiry persistence can be connected later without changing the visual system.
